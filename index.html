How to install

  1. กดปุ่มดาวน์โหลดด้านบน
  2. เปิดไฟล์ MultiRBX-Setup-x.y.z.exe แล้วกด Install (ไม่ต้องใช้สิทธิ์แอดมิน)
  3. เปิด MultiRBX แล้วใส่คีย์ไลเซนส์
  4. จากนั้นโปรแกรมจะอัปเดตตัวเองอัตโนมัติ
  1. Press the download button above.
  2. Run MultiRBX-Setup-x.y.z.exe and press Install (no administrator rights needed).
  3. Open MultiRBX and enter your license key.
  4. From then on it updates itself.

This appears for new apps without a code-signing certificate. Press More info, then Run anyway. You can check the file against the SHA-256 shown below and on the Releases page.

Requirements

  • Windows 10 (64-bit) หรือ Windows 11
  • ติดตั้ง Roblox ไว้แล้ว
  • ไม่ต้องติดตั้ง .NET เพิ่ม
  • Windows 10 (64-bit) or Windows 11
  • Roblox installed
  • No .NET install needed

MultiRBX ไม่ฉีดโค้ด ไม่อ่านหน่วยความจำของ Roblox และไม่ส่งข้อมูลบัญชีไปที่ใดนอกจากเซิร์ฟเวอร์ของ Roblox

MultiRBX never injects code or reads Roblox's memory, and never sends account data anywhere except Roblox's own servers.
