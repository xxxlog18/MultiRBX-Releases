# MultiRBX releases

Download page and update channel for **MultiRBX — Roblox Multi-Instance Manager** (By. iNo).

- Get the latest installer from [Releases](https://github.com/xxxlog18/MultiRBX-Releases/releases/latest).
- MultiRBX checks `releases/latest/download/latest.json` for updates. That file is signed; the app refuses
  any update whose signature, size or SHA-256 doesn't match.

This repository holds release files only. It contains no source code.
